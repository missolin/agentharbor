      「常驻 server」是越少越好的那个数字 —— 它是"每次请求都挂在工具表里的 MCP server 数"。
      · 1（绿色）= 只剩 mount-mcp 自己，它平时一个子 server 都不连；
      · 0（绿色）= 该厂商还没有任何 MCP 配置，不是问题；
      · 数字偏大（红）= 还有 server 常驻在烧 token，点「收敛成 mount-mcp」收掉。

      中心注册表

      id 类型 命令 / 地址 什么时候该挂它

      为什么要这样：一个活着的 MCP server 会把它的完整工具表塞进每一次请求。 chrome-devtools 29 个工具、blender 28 个 —— 放在配置里就是每回合都在付钱，用不用都付。
      收敛之后每家配置里只剩一条 mount-mcp，它平时什么也不连， 只暴露 mcp_list / mcp_mount / mcp_unmount / mcp_call 四个小工具； 要用哪个现挂，用完 mcp_unmount 卸掉，token 还回去。
      改配置前每一家的原文件都会备份到 ，出问题直接拿回来覆盖即可。
      ⚠️ 各客户端要重启才会读到新配置 —— MCP 配置基本都没有热重载。
